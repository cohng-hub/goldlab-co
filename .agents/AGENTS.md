# 에이전트 행동 규칙 (Agent Behavioral Rules)

## 브라우저 자동 실행 금지 및 내부 작업 우선
- 코드 수정이나 사용자 요청 처리 완료 후 브라우저 서브에이전트(`browser_subagent`)를 호출하여 자동으로 웹페이지를 띄우고 UI 검증을 수행하지 않는다. (응답 대기 시간 단축)
- 모든 코드 수정, 로직 보완, 작업 검증은 내부적으로 완결한다.
- 작업 완료 후 핵심 결과 및 변경 사항만 직관적이고 명확하게 사용자에게 즉시 보고한다.
- 사용자가 직접 "브라우저로 확인해 줘" 등의 명시적 요청을 한 경우에만 브라우저 도구를 사용한다.
